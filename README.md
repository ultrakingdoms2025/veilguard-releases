# VeilGuard downloads

VeilGuard stops passwords, API keys, personal and financial data leaking into AI chats, search, chat apps and documents. It checks what you type, paste and upload on your own device before it is sent.

Website: **https://veilguard.site**

## Download

| | Get it |
|---|---|
| Windows app (Windows 10/11, 64-bit) | [Microsoft Store](https://apps.microsoft.com/detail/XPDNLTLCSW4PZW) |

| Browser extension for Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/veilguard-ai-search-leak-guard/) |
